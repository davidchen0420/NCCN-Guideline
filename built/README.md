# OncoCarta, built files

| File | What it is | How to open |
|---|---|---|
| `oncocarta.html` | The library: all 91 encoded guidelines, opening on the atlas (a map of every guideline, its pages and boxes). Each guideline is a compressed script in `guidelines/` beside it. | Open it directly (double-click; keep `guidelines/` next to it), or serve the repository over http (`python -m http.server`, then `http://localhost:8000/built/oncocarta.html`). Needs Safari 16.4, Chrome 80, Firefox 113 or later. |
| `guidelines/<slug>.js` | Each guideline (`data/<slug>/guideline.json` with its example patients), gzip-compressed, for the library page. Generated by `--library`; scripts load from disk where browsers refuse to read data files. | — |
| `prostate-oncocarta.html` | One guideline (Prostate Cancer v6.2026) embedded in a single offline file, with the example patients. | Open it directly in any browser, phone or laptop. |

`screenshots/atlas-*.png` show the atlas home page (light, dark, search, a guideline with an example patient's route, a page card, phone); the other screenshots show an earlier version of the reader.

Rebuild:
```
cd web && npm run build && cd ..                                   # the app -> src/nccn_nav/dashboard.html
PYTHONPATH=src python -m nccn_nav.dashboard --library [--pdfs DIR]  # -> built/oncocarta.html (with the atlas and local PDF paths)
PYTHONPATH=src python -m nccn_nav.dashboard data/prostate built     # -> built/prostate-oncocarta.html (any data/<slug>)
```

To ship the source PDFs with the app, commit your folder of NCCN PDFs as `Guideline/` at the top of the repository (any subfolders; `.gitignore` tracks PDFs only there and at `data/<slug>/pdf/<slug>.pdf`). The library build matches each to its guideline by SHA-256 (else by file name) and records its path:

```
git add Guideline && git commit -m "Add the NCCN source PDFs" && git push
PYTHONPATH=src python -m nccn_nav.dashboard --library
```

PDFs kept elsewhere can be copied into `data/<slug>/pdf/<slug>.pdf` with `PYTHONPATH=src python -m nccn_nav.dashboard --import-pdfs DIR`.

Served from the repository, the page then loads each guideline's PDF itself; a hosted copy serves them as `pdfs/<slug>.pdf` next to the page. Without them, in OncoCarta use "Connect PDF" → "Connect a folder of NCCN PDFs" once (matched to all guidelines by SHA-256 and kept in your browser), or choose or drop a single guideline's PDF.

**Licensing note.** The offline file and the data it reads contain processed NCCN guideline text. NCCN's PDF header says the content may not be distributed or used with an AI model or tool; make sure your agreement with NCCN allows publishing this before keeping the repository public.
