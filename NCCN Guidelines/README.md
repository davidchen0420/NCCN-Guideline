# NCCN Guidelines (source PDFs — not stored in this repo)

The NCCN Guideline PDFs are licensed under a data use agreement and must not be
redistributed. This repository is public, so the PDFs live only in Google Drive
(folder "NCCN Guidelines", ID `1oGM4YrESLXaCLv_V6mxO4dq1NdiISlCl`) and are never committed.

- `manifest.csv` lists every guideline: category, title, Drive file ID, and size.
- To work locally, place the PDFs in this folder under their category
  subfolders (`Treatment/`, `Detection Prevention Risk Reduction/`,
  `Supportive Care/`, `Specific Populations/`). The repo `.gitignore` excludes `*.pdf`.
- Do not commit content derived from the PDFs (extracted text, graphs, benchmarks)
  to this public repo unless the data use agreement permits it.
